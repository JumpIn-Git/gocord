# gocord

A Discord-like chat server built with Go, using [Echo](https://echo.labstack.com/) for HTTP and WebSocket for real-time messaging.

## Features

- Session-based auth (register/login/logout)
- Real-time messaging via WebSocket (new messages, deletions, reactions)
- Emoji reactions
- Server join/leave with invite codes
- Snowflake IDs for all entities
- Turso/libSQL for database (embedded replica or local SQLite)

## Stack

- **Framework:** [Echo v4](https://echo.labstack.com/)
- **Database:** SQLite via [libSQL](https://github.com/tursodatabase/go-libsql) (local or Turso embedded replica)
- **Migrations:** [goose](https://github.com/pressly/goose/v3)
- **Auth:** bcrypt + gorilla/sessions
- **IDs:** Snowflake ([bwmarrin/snowflake](https://github.com/bwmarrin/snowflake))
- **Realtime:** gorilla/websocket

## API

### Auth

| Method | Path                 | Description         |
| ------ | -------------------- | ------------------- |
| POST   | `/api/auth/register` | Register a new user |
| POST   | `/api/auth/login`    | Login               |
| POST   | `/api/auth/logout`   | Logout              |

### Servers

| Method | Path                         | Description                   |
| ------ | ---------------------------- | ----------------------------- |
| POST   | `/api/servers/:server/join`  | Join a server via invite code |
| DELETE | `/api/servers/:server/leave` | Leave a server                |

### Messages

| Method | Path                                     | Description                           |
| ------ | ---------------------------------------- | ------------------------------------- |
| GET    | `/api/servers/:server/messages/:offset`  | Get messages (paginated, 20 per page) |
| POST   | `/api/servers/:server/messages/`         | Post a message                        |
| DELETE | `/api/servers/:server/messages/:message` | Delete a message (own only)           |

### Reactions

| Method | Path                                  | Description           |
| ------ | ------------------------------------- | --------------------- |
| POST   | `/api/servers/:server/react/:message` | Add an emoji reaction |
| DELETE | `/api/servers/:server/react/:message` | Remove a reaction     |

### WebSocket

| Path      | Description                                                             |
| --------- | ----------------------------------------------------------------------- |
| `GET /ws` | Real-time events (`new_msg`, `del_msg`, `new_reaction`, `del_reaction`) |

All routes except register/login require a valid session cookie.

### Localization

API error messages can be localized by passing a `?lang` query parameter with an ISO 639-1 language code (e.g. `?lang=nl`). If omitted, the `Accept-Language` header is used instead. Falls back to English if neither matches a supported locale.

| Language | Code |
| -------- | ---- |
| English  | `en` |
| Dutch    | `nl` |

## Running

```sh
# local SQLite
cd ./cmd/gocord
go run .

# or with Turso
TURSO_DATABASE_URL=libsql://... TURSO_AUTH_TOKEN=... go run .
```

Needs `ENC` and `AUTH` environment variables (32 and 64 bytes respectively, for gorilla/sessions).

## IDs

All `int64` IDs are Snowflake IDs generated by [bwmarrin/snowflake](https://github.com/bwmarrin/snowflake), these are directly sortable (by time).
